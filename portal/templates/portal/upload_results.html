Upload results

Choose the session, semester and course, then upload a file for that one course. Upload one file per course.

The file needs a score column and either a matric_number column, a name column, or both:

  • matric_number, score
  • name, score – a name must match exactly one student, otherwise that row is rejected
  • matric_number, name, score – the name is checked against the matric number

Uploading a score that already exists for the same course and session replaces it.
