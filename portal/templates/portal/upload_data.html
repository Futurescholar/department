Upload data

Upload in this order: Courses, Students, then Guardians and Files (and full-format Results if you are loading old results). Guardians, files and results need the students and courses to exist first.

  • Courses: code, title, credit_units, level, semester and optionally prerequisites (course codes separated by ;). Level is 100 to 500; semester is Harmattan or Rain. If you include the prerequisites column it replaces each listed course's prerequisites (leave a cell blank for none).
  • Students: matric_number, name, surname, email, level (optional: status = Active or Terminated). Each new student gets a login: username = matric number, first password = surname.
  • Results, full format: matric_number, course_code, score, session, semester (semester = Harmattan or Rain; session like 2024/2025)
  • Guardians: matric_number, guardian_email
  • Files: matric_number, file_type, cloud_url

Uploading a row that already exists updates it instead of duplicating it. Normal result uploads by lecturers are on the Upload results page.
